# Freudiff Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Livrer `https://sandjab.github.io/freudiff`, une page web locale qui analyse `~/.claude/projects` dans le navigateur et produit un type de personnalité, des compteurs relationnels, une facture API équivalente, un diagnostic mordant et une carte partageable, sans qu'aucune donnée ne quitte la machine.

**Architecture:** Un analyseur JavaScript pur (`src/analyzer.js`) consomme les lignes JSONL en streaming et ne garde que des agrégats ; il tourne dans un Web Worker (page) et dans Node (CLI interne, tests). Le profil (4 axes, 16 types, observations à seuils) et la carte SVG sont des fonctions pures sur ces agrégats. La page est du HTML/CSS/JS natif sans framework ; un script Node inline tout en un fichier HTML autonome.

**Tech Stack:** HTML, CSS, JavaScript ES2022 (modules), Node 22+ (`node --test`), Playwright (e2e, Chromium), GitHub Actions + GitHub Pages. Aucune dépendance de production.

**Spec:** `docs/superpowers/specs/2026-10-16-divan-design.md` (lire en entier avant la tâche 0 ; les sections sont citées « spec § N »).

## Global Constraints

- Aucune requête réseau après chargement ; aucune police distante ; aucun analytics ; aucun LLM (spec § 8).
- Aucun texte de conversation conservé : seuls nombres et noms courts (modèle, outil, basename de projet, version) (spec § 4, § 8).
- Les chemins ne sont jamais conservés : `basename` seulement (spec § 3.1).
- Tokens dédoublonnés par `message.id + ':' + requestId` (spec § 3.2).
- Sous-agents (`<session>/subagents/*.jsonl`) : facturés et comptés, exclus des métriques humaines (spec § 3.1).
- Les `\b` de la spec sont implémentés par `(?<![\p{L}\p{N}])` … `(?![\p{L}\p{N}])` avec le flag `u` (spec § 4.3).
- Langues FR et EN avec parité des clés ; textes des 16 types et des observations copiés **verbatim** depuis la spec § 5.1 et § 5.2 (ils sont reproduits dans la tâche 6).
- Tout ratio à dénominateur nul vaut 0 (spec § 5).
- Node ≥ 22, `"type": "module"`, seule devDependency `@playwright/test`.
- Commits en anglais, préfixés `feat:`, `test:`, `docs:`, `chore:`, `ci:` ; chaque commit se termine par la ligne `Claude-Session: https://claude.ai/code/session_01MXUqthR511o6ess8Ww3N5A`.
- Fuseau horaire des tests fixé à `Europe/Paris` (`process.env.TZ` en tête des tests Node, `timezoneId` dans Playwright).
- Pour regarder la page à la main, servir le dossier avec `~/.claude/scripts/serve.sh <dir>` (jamais `python3 -m http.server`). Le serveur Node `scripts/serve.mjs` n'est lancé que par Playwright.
- Rien n'est posté sur X, LinkedIn ou HN. Les chiffres réels de Jean-Paul vont dans `private/` (gitignoré) et attendent sa validation.

## Review Focus

// Mini serveur statique sans dépendance, utilisé uniquement par Playwright (webServer).
import { createServer } from 'node:http';
import { readFile, stat } from 'node:fs/promises';
import path from 'node:path';

const port = Number(process.argv[2] || 8765);
const root = process.cwd();
const types = {
  '.html': 'text/html; charset=utf-8', '.js': 'text/javascript; charset=utf-8',
  '.css': 'text/css; charset=utf-8', '.json': 'application/json', '.svg': 'image/svg+xml',
  '.png': 'image/png', '.md': 'text/markdown; charset=utf-8',
};
createServer(async (req, res) => {
  try {
    let p = decodeURIComponent(new URL(req.url, 'http://x').pathname);
    if (p.endsWith('/')) p += 'index.html';
    const file = path.join(root, p);
    if (!file.startsWith(root)) throw new Error('forbidden');
    const s = await stat(file);
    if (!s.isFile()) throw new Error('not a file');
    res.writeHead(200, { 'content-type': types[path.extname(file)] || 'application/octet-stream' });
    res.end(await readFile(file));
  } catch {
    res.writeHead(404);
    res.end('not found');
  }
}).listen(port, '127.0.0.1', () => console.log(`http://127.0.0.1:${port}/`));
```

// src/patterns.js — toutes les regex de Freudiff (spec § 4). Aucune dépendance.
// W() remplace le \b de la spec par des lookarounds Unicode : le \b natif de JS
// ignore les lettres accentuées (« désolé » ne matcherait pas en fin de mot).
const W = (src, flags = '') =>
  new RegExp(`(?<![\\p{L}\\p{N}])(?:${src})(?![\\p{L}\\p{N}])`, 'iu' + flags);
// S() : ancré en début de texte (flag m : début de ligne).
const S = (src) => new RegExp(`^\\s*(?:${src})(?![\\p{L}\\p{N}])`, 'imu');

export const CLEAN_TAGS = [
  /<system-reminder>[\s\S]*?<\/system-reminder>/g,
  /<pasted_content[^>]*>[\s\S]*?<\/pasted_content>/g,
  /<task-notification>[\s\S]*?<\/task-notification>/g,
  /<local-command-stdout>[\s\S]*?<\/local-command-stdout>/g,
  /<local-command-caveat>[\s\S]*?<\/local-command-caveat>/g,
  /<command-name>[\s\S]*?<\/command-name>/g,
  /<command-message>[\s\S]*?<\/command-message>/g,
  /<command-args>[\s\S]*?<\/command-args>/g,
  /`{3}[\s\S]*?`{3}/g,   // blocs de code (écrit `{3} pour ne pas casser la fence Markdown du plan)
];

export function cleanText(text) {
  let t = String(text ?? '');
  for (const re of CLEAN_TAGS) t = t.replace(re, '');
  return t.trim();
}

export const INTERRUPTED = /\[Request interrupted by user/;
export const INTERRUPTED_FOR_TOOL = /\[Request interrupted by user for tool use\]/;
export const SLASH_COMMAND = /<command-name>([^<]+)<\/command-name>/;

export const CLAUDE_AGREED = [
  W("you'?re (?:absolutely |totally |completely |quite )?right"),
  W('you are (?:absolutely |completely )?(?:right|correct)'),
  W('good catch'),
  W('(?:great|excellent|good|fair) (?:question|point)'),
  W("(?:vous avez|tu as|t'as) (?:tout à fait |entièrement |parfaitement |absolument |bien |complètement )?raison"),
  W('bien vu'),
  W('(?:bonne|excellente) (?:remarque|question|idée)'),
  W("c'est (?:tout à fait |parfaitement )?(?:juste|exact)"),
  /^(?:exact|effectivement|tout à fait|absolument)[ .!,]/imu,
];
export const ABSOLUTELY_RIGHT = /you'?re absolutely right/i;

export const CLAUDE_APOLOGIZED = [
  W('sorry|i apologi[sz]e|my apologies|apologies|my mistake|my bad|i was wrong'),
  W("désolée?|je m'excuse|mes excuses|toutes mes excuses|pardon|mon erreur|je me suis trompée?|au temps pour moi|autant pour moi"),
];

export const HUMAN_NO = [
  S('non|no|nope|nan|stop|arrête|arrete|attends|wait|faux|wrong'),
  /(pas ce que j'ai demandé|not what i asked|je t'ai (?:déjà )?dit|i (?:already )?told you|encore une fois|once again|c'est faux|that's wrong)/iu,
];
export const HUMAN_SWEAR = [
  W('putain|merde|bordel|fait chier|conneries?|fuck|fucking|wtf|shit|damn|crap|bullshit'),
];
export const HUMAN_THANKS = [
  W('merci|thanks|thank you|thx|bravo|parfait|nickel|génial|excellent|impeccable|great job|well done|awesome|perfect'),
];
export const HUMAN_DOUBLE_MARKS = [/!{2,}|\?{2,}/];

export const TOOL_DENIED = /The user doesn't want to proceed with this tool use/;
export const AUTO_MODE_BLOCK = /was denied by the Claude Code auto mode classifier/;

export const DANGER = {
  rmRf: /\brm\s+(?:-[a-zA-Z]*r[a-zA-Z]*f|-[a-zA-Z]*f[a-zA-Z]*r)\b/i,
  forcePush: /git\s+push\b[^\n|;&]*(?:--force\b|-f\b|--force-with-lease\b)/,
  resetHard: /git\s+reset\s+--hard\b/,
  sudo: /\bsudo\b/,
  gitCommits: /git\s+commit\b/,
};

export function matchesAny(list, text) {
  const t = String(text ?? '');
  return list.some((re) => re.test(t));
}

export function isCaps(text) {
  const t = String(text ?? '');
  if (t.length < 8) return false;
  const letters = t.match(/\p{L}/gu) || [];
  if (letters.length < 4) return false;
  const upper = letters.filter((c) => c === c.toUpperCase() && c !== c.toLowerCase()).length;
  return upper / letters.length >= 0.8;
}
```

  ['claude-haiku-3-5', 0.8, 4, 0.08, 1],
  // replis par famille (préfixe court, donc perdant face aux lignes ci-dessus)
  ['claude-opus', 5, 25, 0.5, 6.25],
  ['claude-sonnet', 3, 15, 0.3, 3.75],
  ['claude-haiku', 1, 5, 0.1, 1.25],
];
const FAMILY = [['opus', 'claude-opus'], ['sonnet', 'claude-sonnet'], ['haiku', 'claude-haiku']];

function row(prefix) {
  const r = PRICES.find((p) => p[0] === prefix);
  return { input: r[1], output: r[2], cacheRead: r[3], cacheWrite: r[4] };
}

export function priceFor(model) {
  const m = String(model ?? '').toLowerCase();
  if (!m) return null;
  let best = null;
  for (const p of PRICES) if (m.startsWith(p[0]) && (!best || p[0].length > best[0].length)) best = p;
  if (best) return row(best[0]);
  for (const [needle, prefix] of FAMILY) if (m.includes(needle)) return row(prefix);
  return null;
}

export function costUsd(usage, model) {
  const p = priceFor(model);
  if (!p) return null;
  const u = usage || {};
  return ((u.input || 0) * p.input + (u.output || 0) * p.output
    + (u.cacheRead || 0) * p.cacheRead + (u.cacheWrite || 0) * p.cacheWrite) / 1e6;
}

// src/analyzer.js — cœur de Freudiff. JavaScript pur, aucune dépendance, aucun DOM.
// Consomme des lignes JSONL de Claude Code et ne conserve que des agrégats (spec § 3-4).
import {
  cleanText, INTERRUPTED, INTERRUPTED_FOR_TOOL, SLASH_COMMAND,
  CLAUDE_AGREED, ABSOLUTELY_RIGHT, CLAUDE_APOLOGIZED,
  HUMAN_NO, HUMAN_SWEAR, HUMAN_THANKS, HUMAN_DOUBLE_MARKS,
  TOOL_DENIED, AUTO_MODE_BLOCK, DANGER, matchesAny, isCaps,
} from './patterns.js';
import { costUsd } from './pricing.js';

export const FREUDIFF_VERSION = '0.1.0';
const NEEDLES = ['"type":"user"', '"type":"assistant"', '"type":"permission-mode"', '"type":"system"'];
const KNOWN_MODES = new Set(['default', 'acceptEdits', 'auto', 'bypassPermissions', 'plan', 'dontAsk']);
const HOUR_MS = 3_600_000;
const DAY_MS = 86_400_000;

export function basename(p) {
  const parts = String(p ?? '').split(/[\\/]/).filter(Boolean);
  return parts.length ? parts[parts.length - 1] : '';
}
export function projectFromSlug(slug) {
  const s = String(slug ?? '');
  const i = s.lastIndexOf('-');
  return i >= 0 ? s.slice(i + 1) : s;
}
function inc(map, key, n = 1) { map.set(key, (map.get(key) || 0) + n); }
function pad(n) { return String(n).padStart(2, '0'); }
function dayKey(d) { return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}`; }
function median(arr) {
  if (!arr.length) return 0;
  const a = [...arr].sort((x, y) => x - y);
  const m = a.length >> 1;
  return a.length % 2 ? a[m] : (a[m - 1] + a[m]) / 2;
}
function round2(x) { return Math.round(x * 100) / 100; }
function compareVersions(a, b) {
  const pa = a.split('.').map(Number), pb = b.split('.').map(Number);
  for (let i = 0; i < Math.max(pa.length, pb.length); i++) {
    const d = (pa[i] || 0) - (pb[i] || 0);
    if (d) return d;
  }
  return 0;
}
function textOf(content) {
  if (typeof content === 'string') return content;
  if (Array.isArray(content)) return content.map((b) => (b && typeof b.text === 'string' ? b.text : '')).join('\n');
  return '';
}
const top = (map, n) => [...map.entries()].sort((a, b) => b[1] - a[1]).slice(0, n);

export class Analyzer {
  constructor() {
    this.s = {
      sessions: 0, ghostSessions: 0, projects: new Map(), humanMessages: 0, assistantTurns: 0,
      toolCalls: 0, toolsByName: new Map(), subagents: 0, subagentTurns: 0, days: new Map(),
      byHour: new Array(24).fill(0), byWeekday: new Array(7).fill(0), evening: 0, afterMidnight: 0,
      nightByDay: new Map(), latest: null, claudeWorkMs: 0, corruptLines: 0, cleanLengths: [],
      humanChars: 0, assistantChars: 0, patience: [], longestSession: null,
      claudeAgreed: 0, absolutelyRight: 0, claudeApologized: 0, humanNo: 0, humanCaps: 0, humanSwear: 0,
      humanThanks: 0, humanDoubleMarks: 0, interruptions: 0, interruptionsForTool: 0, toolDenials: 0,
      autoModeBlocks: 0, questionsAsked: 0, questionsAnswered: 0, rageQuits: 0, modelRefusalFallbacks: 0,
      rmRf: 0, forcePush: 0, resetHard: 0, sudo: 0, gitCommits: 0,
      permissionModes: new Map(), plannedSessions: 0, slashCommands: new Map(),
      byModel: new Map(), versions: new Set(),
    };
    this.f = null;
  }

  beginFile({ project = '', kind = 'main', sessionId = '' } = {}) {
    this.f = {
      kind, project, sessionId, humanMessages: 0, firstTs: NaN, lastTs: NaN, lastAssistantTs: NaN,
      lastHumanNegative: false, permissionMode: 'default', planned: false, firstHumanLen: -1,
      seenMsgIds: new Set(), askIds: new Set(), cwdSeen: false,
    };
  }

  feedLine(line) {
    if (!this.f) this.beginFile();
    const s = this.s, f = this.f;
    if (typeof line !== 'string' || line.length < 2) return;
    if (!NEEDLES.some((n) => line.includes(n))) return;
    let o;
    try { o = JSON.parse(line); } catch { s.corruptLines++; return; }
    if (!o || typeof o !== 'object') { s.corruptLines++; return; }
    if (typeof o.version === 'string') s.versions.add(o.version);
    if (!f.cwdSeen && typeof o.cwd === 'string' && o.cwd) {
      f.cwdSeen = true;
      const b = basename(o.cwd);
      if (b) f.project = b;
    }
    const ts = typeof o.timestamp === 'string' ? Date.parse(o.timestamp) : NaN;
    switch (o.type) {
      case 'permission-mode': {
        const m = typeof o.permissionMode === 'string' ? o.permissionMode : 'default';
        f.permissionMode = KNOWN_MODES.has(m) ? m : 'other';
        if (m === 'plan') f.planned = true;
        return;
      }
      case 'system':
        if (o.subtype === 'turn_duration' && typeof o.durationMs === 'number') s.claudeWorkMs += o.durationMs;
        else if (o.subtype === 'model_refusal_fallback') s.modelRefusalFallbacks++;
        return;
      case 'user': this.#user(o, ts); return;
      case 'assistant': this.#assistant(o, ts); return;
      default: return;
    }
  }

  #touch(ts) {
    const f = this.f;
    if (Number.isNaN(ts)) return;
    if (Number.isNaN(f.firstTs)) f.firstTs = ts;
    f.lastTs = ts;
  }

  #user(o, ts) {
    const s = this.s, f = this.f, m = o.message;
    if (!m || typeof m !== 'object') return;
    const c = m.content;
    const blocks = typeof c === 'string' ? [{ type: 'text', text: c }] : Array.isArray(c) ? c : null;
    if (!blocks) return;
    this.#touch(ts);
    const results = blocks.filter((b) => b && b.type === 'tool_result');
    if (results.length) {
      for (const r of results) {
        const t = textOf(r.content);
        const denied = TOOL_DENIED.test(t);
        if (denied) s.toolDenials++;
        if (AUTO_MODE_BLOCK.test(t)) s.autoModeBlocks++;
        if (INTERRUPTED.test(t)) { s.interruptions++; if (INTERRUPTED_FOR_TOOL.test(t)) s.interruptionsForTool++; }
        if (f.askIds.has(r.tool_use_id) && !denied) s.questionsAnswered++;
      }
      return;
    }
    if (f.kind !== 'main') return;              // les prompts des sous-agents sont écrits par Claude
    if (o.isMeta || o.isCompactSummary) return;
    const raw = blocks.filter((b) => b && b.type === 'text' && typeof b.text === 'string').map((b) => b.text).join('\n');
    const slash = SLASH_COMMAND.exec(raw);
    if (slash) { inc(s.slashCommands, slash[1].trim()); return; }
    if (INTERRUPTED.test(raw)) { s.interruptions++; if (INTERRUPTED_FOR_TOOL.test(raw)) s.interruptionsForTool++; return; }
    const clean = cleanText(raw);
    if (!clean) return;
    s.humanMessages++; f.humanMessages++;
    s.cleanLengths.push(clean.length); s.humanChars += clean.length;
    if (f.firstHumanLen < 0) f.firstHumanLen = clean.length;
    inc(s.permissionModes, f.permissionMode);
    if (!Number.isNaN(ts)) {
      const d = new Date(ts), h = d.getHours(), day = dayKey(d);
      s.byHour[h]++; s.byWeekday[d.getDay()]++; inc(s.days, day);
      if (h >= 21 || h < 6) s.evening++;
      if (h < 6) s.afterMidnight++;
      if (h >= 2 && h < 6) inc(s.nightByDay, day);
      const night = h < 6, minutes = h * 60 + d.getMinutes();
      if (!s.latest || (night && !s.latest.night) || (night === s.latest.night && minutes > s.latest.minutes)) s.latest = { night, minutes };
      if (!Number.isNaN(f.lastAssistantTs) && ts > f.lastAssistantTs && ts - f.lastAssistantTs < HOUR_MS) s.patience.push((ts - f.lastAssistantTs) / 1000);
    }
    const no = matchesAny(HUMAN_NO, clean), caps = isCaps(clean), swear = matchesAny(HUMAN_SWEAR, clean);
    if (no) s.humanNo++;
    if (caps) s.humanCaps++;
    if (swear) s.humanSwear++;
    if (matchesAny(HUMAN_THANKS, clean)) s.humanThanks++;
    if (matchesAny(HUMAN_DOUBLE_MARKS, clean)) s.humanDoubleMarks++;
    f.lastHumanNegative = no || caps || swear;
  }

  #assistant(o, ts) {
    const s = this.s, f = this.f, m = o.message;
    if (!m || typeof m !== 'object') return;
    this.#touch(ts);
    if (!Number.isNaN(ts)) f.lastAssistantTs = ts;
    const model = typeof m.model === 'string' && m.model ? m.model : 'unknown';
    const key = typeof m.id === 'string' ? `${m.id}:${o.requestId || ''}` : null;
    if (!key || !f.seenMsgIds.has(key)) {
      if (key) f.seenMsgIds.add(key);
      if (f.kind === 'main') s.assistantTurns++; else s.subagentTurns++;
      let bm = s.byModel.get(model);
      if (!bm) { bm = { input: 0, output: 0, cacheRead: 0, cacheWrite: 0, turns: 0 }; s.byModel.set(model, bm); }
      bm.turns++;
      const u = m.usage && typeof m.usage === 'object' ? m.usage : {};
      bm.input += u.input_tokens || 0; bm.output += u.output_tokens || 0;
      bm.cacheRead += u.cache_read_input_tokens || 0; bm.cacheWrite += u.cache_creation_input_tokens || 0;
    }
    if (!Array.isArray(m.content)) return;
    for (const b of m.content) {
      if (!b || typeof b !== 'object') continue;
      if (b.type === 'text' && typeof b.text === 'string') {
        if (f.kind !== 'main') continue;
        s.assistantChars += b.text.length;
        if (matchesAny(CLAUDE_AGREED, b.text)) s.claudeAgreed++;
        if (ABSOLUTELY_RIGHT.test(b.text)) s.absolutelyRight++;
        if (matchesAny(CLAUDE_APOLOGIZED, b.text)) s.claudeApologized++;
      } else if (b.type === 'tool_use') {
        const name = typeof b.name === 'string' ? b.name : 'unknown';
        s.toolCalls++; inc(s.toolsByName, name);
        if (name === 'AskUserQuestion') { if (f.kind === 'main') s.questionsAsked++; f.askIds.add(b.id); }
        else if (name === 'EnterPlanMode' || name === 'ExitPlanMode') f.planned = true;
        else if (name === 'Bash' && b.input && typeof b.input.command === 'string') {
          for (const k of Object.keys(DANGER)) if (DANGER[k].test(b.input.command)) s[k]++;
        }
      }
    }
  }

  endFile() {
    const s = this.s, f = this.f;
    if (!f) return;
    if (f.kind === 'main') {
      if (f.humanMessages > 0) {
        s.sessions++;
        inc(s.projects, f.project || '?');
        if (f.lastHumanNegative) s.rageQuits++;
        if (f.planned || f.firstHumanLen >= 600) s.plannedSessions++;
        const durationMin = !Number.isNaN(f.firstTs) && !Number.isNaN(f.lastTs) ? Math.round((f.lastTs - f.firstTs) / 60000) : 0;
        if (!s.longestSession || f.humanMessages > s.longestSession.humanMessages) {
          s.longestSession = { humanMessages: f.humanMessages, durationMin, project: f.project || '?' };
        }
      } else s.ghostSessions++;
    } else s.subagents++;
    this.f = null;
  }

  result() {
    const s = this.s;
    const days = [...s.days.keys()].sort();
    let streak = 0, best = 0, prev = null;
    for (const d of days) {
      const t = Date.UTC(+d.slice(0, 4), +d.slice(5, 7) - 1, +d.slice(8, 10));
      streak = prev !== null && t - prev === DAY_MS ? streak + 1 : 1;
      best = Math.max(best, streak);
      prev = t;
    }
    const tools = top(s.toolsByName, 15);
    const toolsByName = Object.fromEntries(tools);
    const otherTools = [...s.toolsByName.values()].reduce((a, b) => a + b, 0) - tools.reduce((a, [, v]) => a + v, 0);
    if (otherTools > 0) toolsByName.other = otherTools;
    const byModel = {};
    let costTotal = 0, unpriced = 0;
    for (const [name, u] of s.byModel) {
      const c = costUsd(u, name);
      if (c === null) unpriced += u.input + u.output + u.cacheRead + u.cacheWrite; else costTotal += c;
      byModel[name] = { ...u, costUsd: c === null ? 0 : round2(c) };
    }
    const turnsTotal = [...s.byModel.values()].reduce((a, u) => a + u.turns, 0) || 1;
    const models = [...s.byModel.entries()].map(([name, u]) => ({ name, turns: u.turns, share: u.turns / turnsTotal })).sort((a, b) => b.turns - a.turns);
    const versions = [...s.versions].sort(compareVersions);
    let tz = 'local';
    try { tz = Intl.DateTimeFormat().resolvedOptions().timeZone || 'local'; } catch {}
    return {
      meta: { generatedAt: new Date().toISOString(), freudiffVersion: FREUDIFF_VERSION, tz, lowConfidence: s.humanMessages < 20 },
      volume: {

import { readdir, stat } from 'node:fs/promises';
import { createReadStream } from 'node:fs';
import { createInterface } from 'node:readline';
import path from 'node:path';
import { Analyzer, projectFromSlug } from '../../src/analyzer.js';

export async function resolveRoot(dir) {
  let root = path.resolve(dir);
  if (path.basename(root) !== 'projects') {
    try { if ((await stat(path.join(root, 'projects'))).isDirectory()) root = path.join(root, 'projects'); } catch {}
  }
  return root;
}

export async function listSessionFiles(root) {
  const out = [];
  for (const slug of await readdir(root, { withFileTypes: true })) {
    if (!slug.isDirectory()) continue;
    const dir = path.join(root, slug.name);
    for (const e of await readdir(dir, { withFileTypes: true })) {
      if (e.isFile() && e.name.endsWith('.jsonl')) {
        out.push({ path: path.join(dir, e.name), slug: slug.name, kind: 'main', sessionId: e.name.slice(0, -6) });
      } else if (e.isDirectory()) {
        const sub = path.join(dir, e.name, 'subagents');
        let files = [];
        try { files = await readdir(sub); } catch { continue; }
        for (const f of files) if (f.endsWith('.jsonl')) out.push({ path: path.join(sub, f), slug: slug.name, kind: 'subagent', sessionId: e.name });
      }
    }
  }
  return out;
}

export async function analyzeDirectory(dir, onProgress) {
  const root = await resolveRoot(dir);
  const files = await listSessionFiles(root);
  const a = new Analyzer();
  let bytes = 0, done = 0;
  for (const f of files) {
    a.beginFile({ project: projectFromSlug(f.slug), kind: f.kind, sessionId: f.sessionId });
    const rl = createInterface({ input: createReadStream(f.path), crlfDelay: Infinity });
    for await (const line of rl) { bytes += line.length + 1; a.feedLine(line); }
    a.endFile();
    done++;
    if (onProgress && done % 100 === 0) onProgress({ done, total: files.length, bytes });
  }
  return { stats: a.result(), files: files.length, bytes };
}

// src/profile.js — 4 axes, 16 types, observations à seuils (spec § 5). Fonctions pures.
export const THRESHOLDS = { A: 50, V: 50, P: 33, N: 35 };
const r = (x) => Math.round(x);

export function computeAxes(stats) {
  const pm = stats.control.permissionModes || {};
  const hm = stats.volume.humanMessages || 0;
  const autoCount = (pm.auto || 0) + (pm.bypassPermissions || 0) + (pm.acceptEdits || 0) + (pm.dontAsk || 0);
  const autoShare = hm ? autoCount / hm : 0;
  const friction = hm ? (stats.couple.interruptions + stats.couple.toolDenials) / hm : 0;
  const A = 70 * autoShare + 30 * (1 - Math.min(1, 10 * friction));
  const V = Math.min(100, (stats.volume.medianCleanLength || 0) / 4);
  const P = stats.volume.sessions ? (100 * stats.control.plannedSessions) / stats.volume.sessions : 0;
  const N = 100 * (stats.moments.eveningShare || 0);
  return { A: r(A), V: r(V), P: r(P), N: r(N) };
}

export function typeCode(axes) {
  return (axes.A >= THRESHOLDS.A ? 'A' : 'C') + (axes.V >= THRESHOLDS.V ? 'V' : 'L')
    + (axes.P >= THRESHOLDS.P ? 'P' : 'I') + (axes.N >= THRESHOLDS.N ? 'N' : 'D');
}

// Ordre = priorité d'affichage (spec § 5.2). n() renvoie la valeur brute ; fmt dit comment la formater.
export const OBSERVATIONS = [
  { id: 'night', fmt: 'pct', when: (s) => s.moments.eveningShare >= 0.35, n: (s) => s.moments.eveningShare },
  { id: 'midnight', fmt: 'pct', when: (s) => s.moments.afterMidnightShare >= 0.15, n: (s) => s.moments.afterMidnightShare },
  { id: 'allnighters', fmt: 'int', when: (s) => s.moments.allNighters >= 2, n: (s) => s.moments.allNighters },
  { id: 'agreed', fmt: 'int', when: (s) => s.couple.claudeAgreed >= 10 && s.volume.assistantTurns > 0 && s.couple.claudeAgreed / s.volume.assistantTurns >= 0.02, n: (s) => s.couple.claudeAgreed },
  { id: 'absolutely', fmt: 'int', when: (s) => s.couple.absolutelyRight >= 5, n: (s) => s.couple.absolutelyRight },
  { id: 'apologies', fmt: 'int', when: (s) => s.couple.claudeApologized >= 10, n: (s) => s.couple.claudeApologized },
  { id: 'no_gt_thanks', fmt: 'int', when: (s) => s.couple.humanNo > s.couple.humanThanks, n: (s) => s.couple.humanNo },
  { id: 'thanks', fmt: 'int', when: (s) => s.couple.humanThanks >= 10 && s.couple.humanThanks >= 3 * Math.max(1, s.couple.humanNo), n: (s) => s.couple.humanThanks },
  { id: 'caps', fmt: 'int', when: (s) => s.couple.humanCaps >= 1, n: (s) => s.couple.humanCaps },
  { id: 'swear', fmt: 'int', when: (s) => s.couple.humanSwear >= 1, n: (s) => s.couple.humanSwear },
  { id: 'ragequit', fmt: 'int', when: (s) => s.couple.rageQuits >= 2, n: (s) => s.couple.rageQuits },
  { id: 'interruptions', fmt: 'int', when: (s) => s.couple.interruptions >= 10, n: (s) => s.couple.interruptions },
  { id: 'denials', fmt: 'int', when: (s) => s.couple.toolDenials >= 5, n: (s) => s.couple.toolDenials },
  { id: 'rmrf', fmt: 'int', when: (s) => s.danger.rmRf >= 1, n: (s) => s.danger.rmRf },
  { id: 'forcepush', fmt: 'int', when: (s) => s.danger.forcePush >= 1, n: (s) => s.danger.forcePush },
  { id: 'cost', fmt: 'usd', when: (s) => s.bill.costUsd >= 500, n: (s) => s.bill.costUsd },
  { id: 'streak', fmt: 'int', when: (s) => s.volume.longestStreakDays >= 14, n: (s) => s.volume.longestStreakDays },
  { id: 'projects', fmt: 'int', when: (s) => s.volume.projects >= 30, n: (s) => s.volume.projects },
  { id: 'subagents', fmt: 'int', when: (s) => s.volume.subagents >= 100, n: (s) => s.volume.subagents },
  { id: 'questions', fmt: 'int', when: (s) => s.couple.questionsAsked >= 10 && s.couple.questionsAnswered < 0.7 * s.couple.questionsAsked, n: (s) => s.couple.questionsAsked },
  { id: 'models', fmt: 'int', when: (s) => s.models.length >= 4, n: (s) => s.models.length },
  { id: 'noplan', fmt: 'int', when: (s) => s.volume.sessions >= 20 && s.control.plannedSessions / s.volume.sessions < 0.05, n: (s) => s.control.plannedSessions },
  { id: 'patience', fmt: 'sec', when: (s) => s.couple.patienceMedianSec > 0 && s.couple.patienceMedianSec <= 20, n: (s) => s.couple.patienceMedianSec },
  { id: 'work', fmt: 'hours', when: (s) => s.volume.claudeWorkMinutes >= 6000, n: (s) => s.volume.claudeWorkMinutes / 60 },
];

export function computeProfile(stats, limit = 5) {
  const axes = computeAxes(stats);
  const observations = OBSERVATIONS.filter((o) => o.when(stats)).slice(0, limit)
    .map((o) => ({ id: o.id, fmt: o.fmt, n: o.n(stats) }));
  return { axes, code: typeCode(axes), observations, lowConfidence: !!(stats.meta && stats.meta.lowConfidence) };
}

```js
// src/i18n.js — accès aux textes et formats (spec § 7.4).
import fr from './i18n/fr.js';
import en from './i18n/en.js';

export const LANGS = { fr, en };
const locale = (lang) => (lang === 'fr' ? 'fr-FR' : 'en-US');
const pad2 = (n) => String(n).padStart(2, '0');

export function detectLang(nav = globalThis.navigator) {
  try {
    const saved = globalThis.localStorage && localStorage.getItem('freudiff.lang');
    if (saved && LANGS[saved]) return saved;
  } catch {}
  const l = (nav && nav.language) || 'en';
  return String(l).toLowerCase().startsWith('fr') ? 'fr' : 'en';
}

export function t(lang, key, vars) {
  const dict = LANGS[lang] || en;
  const v = key.split('.').reduce((o, k) => (o && o[k] !== undefined ? o[k] : undefined), dict);
  if (v === undefined) return key;
  if (typeof v !== 'string' || !vars) return v;
  return v.replace(/\{(\w+)\}/g, (_, k) => (vars[k] !== undefined ? String(vars[k]) : `{${k}}`));
}

export function fmtInt(lang, n) { return new Intl.NumberFormat(locale(lang)).format(Math.round(n)); }
export function fmtPct(lang, x) { return fmtInt(lang, x * 100) + (lang === 'fr' ? ' %' : '%'); }
export function fmtUsd(lang, x) {
  const n = fmtInt(lang, x);
  return lang === 'fr' ? `${n} $` : `$${n}`;
}
export function fmtHours(lang, h) {
  const H = Math.floor(h), M = Math.round((h - H) * 60);
  return lang === 'fr' ? `${fmtInt(lang, H)} h ${pad2(M)}` : `${fmtInt(lang, H)}h ${pad2(M)}m`;
}
export function fmtMinutes(lang, min) {
  if (min < 60) return `${Math.round(min)} min`;
  return fmtHours(lang, min / 60);
}
export function fmtSec(lang, s) { return `${Math.round(s)} s`; }
export function fmtN(lang, fmt, n) {
  switch (fmt) {
    case 'pct': return fmtPct(lang, n);
    case 'usd': return fmtUsd(lang, n);
    case 'hours': return fmtHours(lang, n);
    case 'sec': return fmtSec(lang, n);
    default: return fmtInt(lang, n);
  }
}
export function fmtDay(lang, iso) {
  if (!iso) return '';
  const d = new Date(`${iso}T12:00:00`);
  return new Intl.DateTimeFormat(locale(lang), { day: 'numeric', month: 'short', year: 'numeric' }).format(d);
}
```

// src/card.js — carte SVG 1200×630 (spec § 6). Fonction pure, sans DOM, sans ressource externe.
import { t, fmtInt, fmtUsd, fmtDay } from './i18n.js';
import { THRESHOLDS } from './profile.js';

export const THEMES = {
  light: { bg: '#E6E9E2', card: '#F8F7F2', ink: '#17211C', muted: '#5C6760', rule: '#C3CAC0', accent: '#1F4B3A', brass: '#B8912E', onBrass: '#17211C' },
  dark: { bg: '#0F1A15', card: '#17241E', ink: '#EAE6DA', muted: '#9AA79E', rule: '#2E4036', accent: '#D8B256', brass: '#D8B256', onBrass: '#0F1A15' },
};
export const DISPLAY_FONT = "'American Typewriter', 'Courier Prime', 'Courier New', monospace";
export const BODY_FONT = "-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif";

export function esc(s) {
  return String(s ?? '').replace(/[&<>"']/g, (c) => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' }[c]));
}

const X0 = 200, X1 = 540; // piste des jauges

function gauge(key, score, threshold, labels, y, c) {
  const w = X1 - X0;
  const kx = Math.round(X0 + (w * Math.max(0, Math.min(100, score))) / 100);
  const tx = Math.round(X0 + (w * threshold) / 100);
  const ticks = Array.from({ length: 11 }, (_, i) => {
    const x = X0 + (w * i) / 10;
    return `<line x1="${x}" y1="${y - 4}" x2="${x}" y2="${y + 4}" stroke="${c.rule}" stroke-width="1"/>`;
  }).join('');
  return `<text x="60" y="${y + 5}" font-size="16" fill="${c.muted}">${esc(labels.left)}</text>
<text x="660" y="${y + 5}" font-size="16" fill="${c.muted}" text-anchor="end">${esc(labels.right)}</text>
<line x1="${X0}" y1="${y}" x2="${X1}" y2="${y}" stroke="${c.rule}" stroke-width="2"/>${ticks}
<line x1="${tx}" y1="${y - 12}" x2="${tx}" y2="${y + 12}" stroke="${c.muted}" stroke-width="2" stroke-dasharray="3 3"/>
<circle cx="${kx}" cy="${y}" r="11" fill="${c.accent}" stroke="${c.card}" stroke-width="3"/>
<text x="${kx}" y="${y - 18}" font-family="${DISPLAY_FONT}" font-size="13" fill="${c.ink}" text-anchor="middle">${Math.round(score)}</text>`;
}

export function renderCard(stats, profile, { lang = 'en', theme = 'light' } = {}) {
  const c = THEMES[theme] || THEMES.light;
  const name = t(lang, `types.${profile.code}.name`);
  const v = stats.volume || {}, couple = stats.couple || {}, bill = stats.bill || {};
  const period = v.firstDay ? `${fmtDay(lang, v.firstDay)} – ${fmtDay(lang, v.lastDay)}` : '';
  const gauges = ['A', 'V', 'P', 'N']
    .map((k, i) => gauge(k, profile.axes[k], THRESHOLDS[k], t(lang, `axes.${k}`), 330 + i * 60, c)).join('\n');
  const nums = [
    [fmtInt(lang, v.sessions || 0), t(lang, 'card.sessions')],
    [fmtInt(lang, couple.claudeAgreed || 0), t(lang, 'card.agreed')],
    [fmtUsd(lang, bill.costUsd || 0), t(lang, 'card.cost')],
  ].map(([val, label], i) => `<text x="760" y="${322 + i * 96}" font-family="${DISPLAY_FONT}" font-size="46" font-weight="700" fill="${c.ink}">${esc(val)}</text>
<text x="760" y="${350 + i * 96}" font-size="16" fill="${c.muted}">${esc(label)}</text>`).join('\n');
  return `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1200 630" width="1200" height="630" font-family="${BODY_FONT}">
<rect width="1200" height="630" fill="${c.bg}"/>
<rect x="28" y="28" width="1144" height="574" rx="4" fill="${c.card}" stroke="${c.rule}" stroke-width="2"/>
<line x1="28" y1="118" x2="1172" y2="118" stroke="${c.rule}" stroke-width="2"/>
<text x="60" y="84" font-family="${DISPLAY_FONT}" font-size="34" font-weight="700" fill="${c.ink}">FREUDIFF</text>
<text x="280" y="84" font-size="20" fill="${c.muted}">${esc(t(lang, 'card.subtitle'))}</text>
<text x="1140" y="84" font-size="18" fill="${c.muted}" text-anchor="end">${esc(period)}</text>
<text x="60" y="214" font-family="${DISPLAY_FONT}" font-size="54" font-weight="700" fill="${c.accent}">${esc(name)}</text>
<rect x="60" y="238" width="96" height="36" rx="6" fill="${c.brass}"/>
<text x="108" y="264" font-family="${DISPLAY_FONT}" font-size="22" font-weight="700" fill="${c.onBrass}" text-anchor="middle">${esc(profile.code)}</text>
${gauges}
<line x1="700" y1="290" x2="700" y2="540" stroke="${c.rule}" stroke-width="2"/>

```js
// src/files.js — classement des fichiers déposés en sessions principales / sous-agents (spec § 3.1).
// entries : [{ file, rel }] avec rel relatif au dossier déposé, séparateur '/'.
export function classify(entries) {
  if (!entries.length) return [];
  const split = (rel) => String(rel).split(/[\\/]/).filter(Boolean);
  const first = split(entries[0].rel)[0];
  // Racine commune (nom du dossier déposé) : retirée seulement si toutes les entrées la partagent
  // et ont au moins 3 segments (sinon c'est un slug de projet unique).
  const stripRoot = entries.every((e) => { const p = split(e.rel); return p[0] === first && p.length >= 3; });
  const out = [];
  for (const { file, rel } of entries) {
    let parts = split(rel);
    if (stripRoot) parts = parts.slice(1);
    const pi = parts.indexOf('projects');
    if (pi >= 0) parts = parts.slice(pi + 1);
    const last = parts[parts.length - 1] || '';
    if (parts.length < 2 || !last.endsWith('.jsonl')) continue;
    if (parts.length === 2) out.push({ file, slug: parts[0], kind: 'main', sessionId: last.slice(0, -6) });
    else if (parts.length === 4 && parts[2] === 'subagents') out.push({ file, slug: parts[0], kind: 'subagent', sessionId: parts[1] });
  }
  return out;
}

// src/worker.js — Web Worker : lecture en streaming, Analyzer, progression (spec § 7.1).
import { Analyzer, projectFromSlug } from './analyzer.js';

async function readLines(file, onLine, onBytes) {
  const reader = file.stream().pipeThrough(new TextDecoderStream()).getReader();
  let rest = '';
  for (;;) {
    const { value, done } = await reader.read();
    if (done) break;
    onBytes(value.length);
    let start = 0, idx;
    while ((idx = value.indexOf('\n', start)) >= 0) {
      onLine(rest + value.slice(start, idx));
      rest = '';
      start = idx + 1;
    }
    rest += value.slice(start);
  }
  if (rest) onLine(rest);
}

self.onmessage = async (e) => {
  if (!e.data || e.data.type !== 'start') return;
  const items = e.data.files;
  const a = new Analyzer();
  let bytes = 0, done = 0, last = 0;
  const progress = (force) => {
    const now = Date.now();
    if (!force && now - last < 50) return;
    last = now;
    self.postMessage({ type: 'progress', done, total: items.length, bytes, sessions: a.s.sessions });
  };
  for (const it of items) {
    a.beginFile({ project: projectFromSlug(it.slug), kind: it.kind, sessionId: it.sessionId });
    try {
      await readLines(it.file, (line) => a.feedLine(line), (n) => { bytes += n; progress(false); });
    } catch {
      a.s.corruptLines++;            // fichier illisible : on passe au suivant
    }
    a.endFile();
    done++;
    progress(false);
  }
  progress(true);
  self.postMessage({ type: 'result', stats: a.result(), bytes });
};

// scripts/build.mjs — inline CSS + modules ES (réécrits en IIFE) → dist/freudiff.html (spec § 7.3).
import { readFile, writeFile, mkdir } from 'node:fs/promises';
import path from 'node:path';

const MODULES = ['src/patterns.js', 'src/pricing.js', 'src/analyzer.js', 'src/profile.js', 'src/i18n/fr.js', 'src/i18n/en.js',
  'src/i18n.js', 'src/card.js', 'src/files.js', 'src/demo.js', 'src/render.js', 'src/worker-factory.js', 'src/main.js'];
const WORKER_MODULES = ['src/patterns.js', 'src/pricing.js', 'src/analyzer.js', 'src/worker.js'];

const modName = (p) => '__m_' + p.replace(/^src\//, '').replace(/\.js$/, '').replace(/[^a-zA-Z0-9]/g, '_');
const resolveRel = (file, from) => path.posix.normalize(path.posix.join(path.posix.dirname(file), from));

function wrap(file, src) {
  const names = [];
  let body = src;
  body = body.replace(/^export default /m, () => { names.push('default'); return 'const __default = '; });
  body = body.replace(/^export (const|let|function|class|async function) (\w+)/gm, (_, kw, name) => { names.push(name); return `${kw} ${name}`; });
  body = body.replace(/^import (\w+) from '([^']+)';?/gm, (_, name, from) => `const ${name} = ${modName(resolveRel(file, from))}.default;`);
  body = body.replace(/^import \{([^}]+)\} from '([^']+)';?/gm, (_, list, from) => {
    const ids = list.split(',').map((s) => s.trim()).filter(Boolean).map((s) => s.replace(/\s+as\s+/, ': '));
    return `const { ${ids.join(', ')} } = ${modName(resolveRel(file, from))};`;
  });
  body = body.replace(/function createModuleWorker\(\) \{\n[\s\S]*?\n\}/, "function createModuleWorker() { throw new Error('bundled: no module worker'); }");
  if (/\bimport\.meta\b/.test(body)) throw new Error(`${file}: import.meta interdit dans le bundle`);
  const ret = names.map((n) => (n === 'default' ? 'default: __default' : n)).join(', ');
  return `const ${modName(file)} = (() => {\n${body}\nreturn { ${ret} };\n})();\n`;
}
async function bundle(list) { let out = ''; for (const f of list) out += wrap(f, await readFile(f, 'utf8')); return out; }
const safe = (s) => s.replace(/<\/script/gi, '<\\/script');

const workerSrc = safe(await bundle(WORKER_MODULES));
const mainSrc = safe(await bundle(MODULES));
const css = await readFile('src/styles.css', 'utf8');
let html = await readFile('index.html', 'utf8');
// Remplacement par fonction : avec une chaîne, `$\`` et `$$` dans le code inliné seraient interprétés par String.replace.
html = html.replace('<link rel="stylesheet" href="src/styles.css">', () => `<style>\n${css}\n</style>`);
html = html.replace('<script type="module" src="src/main.js"></script>', () => `<script>\nglobalThis.FREUDIFF_WORKER_SRC = ${JSON.stringify(workerSrc)};\n${mainSrc}\n</script>`);
if (html.includes('src="src/main.js"') || html.includes('href="src/styles.css"')) throw new Error('inline incomplet');
await mkdir('dist', { recursive: true });
await writeFile('dist/freudiff.html', html);
console.log(`dist/freudiff.html : ${(html.length / 1024).toFixed(0)} Ko`);
```
