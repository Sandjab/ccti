# Décompression des sessions Codex `.jsonl.zst` — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** lire les sessions Codex `rollout-*.jsonl.zst` dans le navigateur, comme les `.jsonl`, sans aucune requête réseau.

**Architecture:** fzstd 0.1.1 est recopié tel quel dans `vendor/fzstd.js`. Le Web Worker (`src/worker-core.js`) insère un `TransformStream` de décompression avant le `TextDecoderStream` pour les items `zst: true`. Le tri (`codex/files.js`, `src/sources.js`) marque ces items, écarte l'archive quand le `.jsonl` de la même session est là, et le reçu compte décompressées, doublons et illisibles. L'assemblage (`scripts/build.mjs`) sait réécrire les formes d'export de fzstd.

**Tech Stack:** JavaScript ES modules sans dépendance, Web Worker, Streams API, `node:test`, Playwright, `node:zlib` (`zstdCompressSync`, Node ≥ 22.15) pour les fixtures et les tests.

**Spec:** `docs/superpowers/specs/2026-10-18-codex-zst-design.md`

## Global Constraints

- Aucune requête réseau depuis la page : pas de CDN, pas de npm à l'exécution, pas de WebAssembly.
- `vendor/fzstd.js` : corps identique octet pour octet à `package/esm/index.mjs` de `fzstd@0.1.1` (SHA-256 `1a901fc5a58c349bbdb4f2aa1e688637ef56891ec58243a9f0cd863166b0d2a4`), précédé d'un en-tête (provenance, licence MIT complète) qui finit par la ligne exacte `// ---- fzstd@0.1.1, esm/index.mjs, inchangé ci-dessous ----`.
- Clé JSON du reçu conservée : `compressed` ; nouvelle clé : `duplicates`.
- Textes : FR « archives .jsonl.zst décompressées », EN « decompressed .jsonl.zst archives » ; FR « archives déjà décompressées », EN « already decompressed archives » ; plus aucune mention de « zstd -d ».
- Doublons : par `sessionId`, seulement entre `.jsonl` et `.jsonl.zst` ; le `.jsonl` l'emporte.
- Hors périmètre : CLI, autres formats compressés, image OG, GIF.
- Commentaires de code en français, dans le style existant (renvoi à la spec : `(spec .zst § N)`). Messages de commit en anglais, style `feat:` / `test:` / `docs:`, terminés par la ligne `Claude-Session: https://claude.ai/code/session_0192DpdSD1TXL3ZbPURJoh8q`.
- Travail sur la branche `codex-zst`, créée depuis `main`. Pas de push ni de fusion sans accord de Jean-Paul.

## Review Focus

1. Une ligne JSON ou un caractère UTF-8 multi-octet coupés entre deux blocs décompressés doivent être recollés : le bilan d'un gros `.zst` est identique à celui du `.jsonl` (test « gros .zst », tâche 2).
2. Un `.zst` tronqué ou faux ne bloque pas l'analyse : il est compté dans `unreadable.compressed` et les fichiers suivants sont lus (tâche 2).
3. Un `.zst` vide (0 octet) : fzstd ne lève pas d'erreur, aucune ligne. Il est traité comme un `.jsonl` vide, pas comme un fichier illisible (tâche 2).
4. Une session présente sous les deux formes n'est lue qu'une fois, quel que soit l'ordre des dépôts (tâche 3).
5. Le fichier autonome (worker Blob, `file://`) évalue fzstd et lit un vrai `.zst` sans requête (tâches 1 et 4).

Effet connu, non modifié : un fichier illisible passe par `beginFile`/`endFile` et compte comme une « session fantôme » (comportement existant pour les fichiers Claude illisibles). Le faux `f6.jsonl.zst` des fixtures ajoute donc une session fantôme au bilan affiché ; le profil n'en dépend pas.

- [ ] **Step 4 : créer `scripts/lib/bundle.mjs`**

Déplacer `modName`, `resolveRel` et `wrap` depuis `scripts/build.mjs`, avec deux formes d'export de plus et un garde-fou :

```js
// scripts/lib/bundle.mjs — réécrit un module ES en IIFE pour le fichier autonome (spec § 7.3 ;
// spec .zst § 2). Partagé par scripts/build.mjs et les tests.
import path from 'node:path';

export const modName = (p) => '__m_' + p.replace(/^src\//, '').replace(/\.js$/, '').replace(/[^a-zA-Z0-9]/g, '_');
const resolveRel = (file, from) => path.posix.normalize(path.posix.join(path.posix.dirname(file), from));

export function wrap(file, src) {
  const names = [];
  let body = src;
  body = body.replace(/^export default /m, () => { names.push('default'); return 'const __default = '; });
  body = body.replace(/^export (const|let|var|function|class|async function) (\w+)/gm, (_, kw, name) => { names.push(name); return `${kw} ${name}`; });
  // `export { A, B };` (fzstd) : la ligne disparaît, les noms sont exportés.
  body = body.replace(/^export \{([^}]+)\};?[ \t]*$/gm, (_, list) => { names.push(...list.split(',').map((s) => s.trim()).filter(Boolean)); return ''; });
  body = body.replace(/^import (\w+) from '([^']+)';?/gm, (_, name, from) => `const ${name} = ${modName(resolveRel(file, from))}.default;`);
  body = body.replace(/^import \{([^}]+)\} from '([^']+)';?/gm, (_, list, from) => {
    const ids = list.split(',').map((s) => s.trim()).filter(Boolean).map((s) => s.replace(/\s+as\s+/, ': '));
    return `const { ${ids.join(', ')} } = ${modName(resolveRel(file, from))};`;
  });
  body = body.replace(/function createModuleWorker\(\) \{\n[\s\S]*?\n\}/, "function createModuleWorker() { throw new Error('bundled: no module worker'); }");
  // Garde-fou : un export non réécrit casserait le script classique du fichier autonome.
  if (/^export\b/m.test(body) || names.some((n) => !/^\w+$/.test(n))) throw new Error(`${file} : forme d'export non prise en charge`);
  if (/\bimport\.meta\b/.test(body)) throw new Error(`${file}: import.meta interdit dans le bundle`);
  const ret = names.map((n) => (n === 'default' ? 'default: __default' : n)).join(', ');
  return `const ${modName(file)} = (() => {\n${body}\nreturn { ${ret} };\n})();\n`;
}
```

function unzstd() {
  let d;

    flush() { d.push(new Uint8Array(0), true); },
  });

export function classify(entries) {
  const out = [];
  for (const { file, rel } of entries) {
    const name = String(rel).split(/[\\/]/).pop() || '';
    if (!name.startsWith('rollout-')) continue;
    if (name.endsWith('.jsonl')) out.push({ file, sessionId: name.slice(0, -6) });
    // compressé (zstd) : décompressé en flux par le worker (spec .zst § 4)
    else if (name.endsWith('.jsonl.zst')) out.push({ file, sessionId: name.slice(0, -10), zst: true });
  }
  // zstd -d garde l'archive : si le .jsonl de la même session est là, il l'emporte (spec .zst, décision 5).
  const plain = new Set(out.filter((o) => !o.zst).map((o) => o.sessionId));
  return out.filter((o) => !(o.zst && plain.has(o.sessionId)));
}

export function addBatch(items, entries) {
  const seen = new Set(items.map((it) => keyOf(it.file)));
  let out = [...items];
  let added = 0;
  for (const it of classify(entries)) {
    const k = keyOf(it.file);
